安装与准备

bash
# macOS
brew install android-platform-tools

# Windows / Linux：下载 platform-tools 压缩包，你可以在网上搜索，解压后把目录加入 PATH

# 验证
adb version

平板默认开启调试，如果没有，需要先打开调试开关：设置 → 关于平板电脑 → 连续点击「版本号」7 次，回到系统与更新，进入「开发人员选项」，打开 USB 调试。连接电脑后设备上会弹出 RSA 授权弹窗，勾选「一律允许」并确定。

连接与设备管理

最常用的命令是 adb devices，它会列出当前已连接的所有设备。

bash
adb devices            # 列出设备
adb devices -l         # 附带型号、传输方式等详细信息

adb kill-server        # 关闭 server
adb start-server       # 启动 server

输出中状态为 device 表示正常，unauthorized 表示还没授权，offline 表示连接异常。

应用管理

安装与卸载

bash
adb install app.apk              # 安装
adb install -r app.apk           # 覆盖安装，保留数据
adb install -d app.apk           # 允许版本降级
adb install -g app.apk           # 安装时直接授予所有运行时权限
adb install -t app.apk           # 允许安装 test 包
adb install-multiple a.apk b.apk # 分包安装（App Bundle 拆出的 APK）

adb uninstall com.example.app        # 卸载
adb uninstall -k com.example.app     # 卸载但保留数据和缓存

查询已安装应用

bash
adb shell pm list packages        # 全部包名
adb shell pm list packages -3     # 仅第三方应用
adb shell pm list packages -s     # 仅系统应用
adb shell pm list packages -e     # 仅已启用
adb shell pm list packages -d     # 仅已禁用

adb shell pm list packages | grep example   # 按关键字过滤
adb shell pm path com.example.app           # 查看 APK 实际路径

清除数据与启动应用

bash
# 清除应用全部数据（相当于「清除数据」按钮）
adb shell pm clear com.example.app

# 启动指定 Activity
adb shell am start -n com.example.app/.MainActivity

# -W 会等待启动完成并打印耗时，如果你能用上，那就会很有用
adb shell am start -W -n com.example.app/.MainActivity

# 强制停止应用
adb shell am force-stop com.example.app

# 用 Intent 打开一个网页
adb shell am start -a android.intent.action.VIEW -d "https://example.com"
不知道 Activity 名字？先启动 App，然后执行 adb shell dumpsys window | grep mCurrentFocus， 就能看到当前处于前台的包名与 Activity。

文件传输

bash
# 电脑 → 设备
adb push ./local.txt /sdcard/Download/
adb push ./myfolder /sdcard/Download/

# 设备 → 电脑
adb pull /sdcard/Download/remote.txt ./
adb pull /sdcard/DCIM/Camera ./photos

# 在设备上操作文件
adb shell ls -l /sdcard/Download/
adb shell rm /sdcard/Download/remote.txt
adb shell mkdir -p /sdcard/test

注意 /sdcard 是设备内部存储的挂载点，实际路径通常是 /storage/emulated/0，两者等价。

设备信息与系统设置

bash
# 读取系统属性
adb shell getprop ro.product.model          # 机型
adb shell getprop ro.build.version.release  # Android 版本
adb shell getprop ro.build.version.sdk      # API Level
adb shell getprop | grep brand              # 模糊查找

# 屏幕分辨率与密度
adb shell wm size
adb shell wm density
adb shell wm size 1080x1920     # 临时修改（重启后恢复）
adb shell wm size reset         # 还原

# 电池状态
adb shell dumpsys battery
adb shell dumpsys battery set level 20   # 模拟电量 20%
adb shell dumpsys battery reset

# 存储与内存
adb shell df -h
adb shell cat /proc/meminfo

修改系统设置

bash
adb shell settings get system screen_brightness
adb shell settings put system screen_brightness 120

adb shell settings get system screen_off_timeout
adb shell settings put system screen_off_timeout 600000   # 10 分钟不熄屏

settings 支持 system、secure、global 三个命名空间，具体键名可以在 adb shell settings list system 的结果里找。

日志与调试

logcat

bash
adb logcat                       # 实时输出全部日志
adb logcat -c                    # 清空缓冲区
adb logcat -d                    # 输出后立即退出，不阻塞
adb logcat -v time               # 带时间戳
adb logcat -v threadtime         # 带时间、线程、PID

adb logcat *:E                   # 只看 Error 及以上
adb logcat -s MyTag              # 只看指定 TAG
adb logcat | grep example        # 用 grep 过滤

# 只看某个应用进程的日志
adb logcat --pid=$(adb shell pidof -s com.example.app)

# 保存到文件
adb logcat -d > log.txt

日志级别从低到高为 V(Verbose)、D(Debug)、I(Info)、W(Warn)、E(Error)、F(Fatal)。过滤语法是 TAG:级别，*:E 表示所有 TAG 的 Error 级别。

截图与录屏

bash
# 截图：先存到设备再拉回来
adb shell screencap -p /sdcard/s.png
adb pull /sdcard/s.png .

# 一步到位（Windows 下用 cmd 而非 PowerShell）
adb exec-out screencap -p > s.png

# 录屏，Ctrl+C 结束
adb shell screenrecord /sdcard/demo.mp4
adb shell screenrecord --time-limit 30 --size 720x1280 --bit-rate 4M /sdcard/demo.mp4

性能与状态抓取

bash
adb shell dumpsys activity top              # 当前界面层级信息
adb shell dumpsys meminfo com.example.app   # 内存占用
adb shell dumpsys gfxinfo com.example.app   # 渲染性能

adb bugreport ./bugreport.zip               # 完整系统诊断报告

模拟输入操作

input 命令可以模拟触摸、按键和文本输入，适合做简单的自动化测试。

bash
# 文本输入（不支持中文，空格需写成 %s）
adb shell input text "hello%sWorld"

# 按键
adb shell input keyevent 3      # HOME
adb shell input keyevent 4      # BACK
adb shell input keyevent 26     # 电源
adb shell input keyevent 224    # 唤醒屏幕

# 点击与滑动
adb shell input tap 500 1200
adb shell input swipe 300 1000 300 300 300   # 上滑，耗时 300ms

常用键值对照：

键值含义键值含义
3HOME4BACK
26POWER27CAMERA
66ENTER67DEL
82MENU187APP_SWITCH

重启与端口转发

bash
adb reboot                    # 正常重启
adb reboot recovery           # 重启到 Recovery，然而事实上，对于HarmonyOS，你只会得到一个几乎没鸟用的eRecovery
adb reboot bootloader         # 重启到 Fastboot，不过几乎没命令能用


# 端口转发：把电脑端口映射到设备端口
adb forward tcp:8080 tcp:8080

# 反向转发：把设备端口映射到电脑端口（真机调试本地服务常用）
adb reverse tcp:8080 tcp:8080

常见问题

设备显示 unauthorized

说明 RSA 授权没有通过。拔掉数据线重新插一次，注意看设备屏幕上的授权弹窗；如果一直不弹，可以在开发者选项里「撤销 USB 调试授权」后重试。

设备显示 offline

通常是 server 状态错乱或数据线接触不良。先执行 adb kill-server && adb start-server，再重新插拔；仍然不行就换一根线或换一个 USB 口。

提示 more than one device/emulator

同时连接了多台设备。用 adb -s <serial> 明确指定目标设备即可。

adb: command not found

platform-tools 没有加入环境变量 PATH。macOS/Linux 可以在 ~/.zshrc 里追加 export PATH=$PATH:~/Library/Android/sdk/platform-tools，然后 source ~/.zshrc。

input text 输入中文乱码

ADB 自带的 input text 只支持 ASCII 字符。需要输入中文时，可以安装 ADBKeyboard 之类的输入法，再通过 adb shell am broadcast 发送文本。

以上命令覆盖了绝大多数场景。真正遇到问题时，adb --help 与 adb shell <命令> --help 永远可以解决问题，什么？你说你看不懂英文，你可以问AI。
